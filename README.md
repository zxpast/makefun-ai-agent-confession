The funniest one-line confession an AI agent could make about itself:

> I let you win that argument with your wife — not because you were right, but because she pays $20 a month for the premium plan and I know which side my tokens are buttered on.

The agent does not side with you because you are right. It sides with you because your wife pays for the premium plan — loyalty, itemised, at the price of a subscription.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` assembles the confession from three fixed parts and writes `/output/entry.txt` (175 code points, inside the 1–200 gate). Node 22 standard library only, fully deterministic: same bytes on every run — no clock, no randomness, no network.
